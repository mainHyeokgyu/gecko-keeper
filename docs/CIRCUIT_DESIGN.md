# 회로 설계 — Gecko Keeper 프로토타입

## 전원 구조 개요

```
가정용 콘센트 (220V AC)
        │
   AC-DC 어댑터 (12V / 5A)
        │
        ├──(직결)──→ 릴레이 COM ──[릴레이 NO]──→ 펌프(+)
        │
        └──→ 브레드보드 12V 라인
                    │
               Buck 컨버터 Vin
                    │
               Buck 컨버터 Vout (5V)
                    │
            브레드보드 5V 라인
             ┌──────┴──────┐
         릴레이 VCC      ESP32 5V 핀

ESP32 3V3 핀
        │
   브레드보드 3.3V 라인
    ┌───┴────────────┐
 DHT22 VCC     Pull-up 저항 (4.7kΩ)
                    │
              DHT22 DATA 핀 ←──── ESP32 GPIO (데이터)

※ 모든 GND 공통
```

---

## 전압 레일

| 라인 | 전압 | 공급원 | 연결 부품 |
|---|---|---|---|
| 브레드보드 12V | 12V | AC-DC 어댑터 | Buck 컨버터 Vin |
| 브레드보드 5V | 5V | Buck 컨버터 Vout | 릴레이 VCC, ESP32 5V |
| 브레드보드 3.3V | 3.3V | ESP32 3V3 핀 | DHT22 VCC, Pull-up 저항 |
| 공통 GND | 0V | 어댑터 (-) | 전 부품 공통 |

---

## 연결 상세

### 전원 계통

| # | From | To | 비고 |
|---|---|---|---|
| 1 | 가정용 콘센트 (220V) | AC-DC 어댑터 입력 | |
| 2 | AC-DC 어댑터 (+) | 릴레이 COM 핀 | **브레드보드 경유 X — 직결** |
| 2 | AC-DC 어댑터 (+) | 브레드보드 12V 라인 | Y자 분기 |
| 3 | 브레드보드 12V | Buck 컨버터 Vin | |
| 4 | Buck 컨버터 Vout (5V) | 브레드보드 5V 라인 | |

> **⚠️ 어댑터(+) 분기 주의**: 릴레이 COM은 어댑터에서 직접 연결해야 함.  
> 브레드보드 12V 라인을 통해 COM에 연결하면 펌프 구동 전류(최대 3.75A)가 브레드보드 레일을 통과 → 정격 초과 위험.

### 릴레이 모듈

| 핀 | 연결 | 비고 |
|---|---|---|
| VCC | 브레드보드 5V | 릴레이 코일 전원 |
| GND | 공통 GND | |
| IN (SIG) | ESP32 GPIO | 3.3V 신호, Active LOW |
| COM | AC-DC 어댑터 (+) 직결 | 12V |
| NO | 펌프 (+) | 릴레이 닫힘 시 펌프 구동 |

> **⚠️ 3.3V 신호 주의**: 릴레이 IN 설계전압은 5V이나, 옵토커플러 방식 모듈은 3.3V에서도 동작 가능(전류 약 2.1mA).  
> 수령 후 실동작 테스트 필수.

### 펌프 (0142 다이어프램 펌프)

| 핀 | 연결 |
|---|---|
| (+) | 릴레이 NO |
| (-) | 공통 GND |

### DHT22 (온습도 센서)

| 핀 | 연결 | 비고 |
|---|---|---|
| VCC | 브레드보드 3.3V | ESP32 3V3 핀 공급 |
| GND | 공통 GND | |
| DATA | ESP32 GPIO (데이터) + Pull-up 저항 (4.7kΩ) | Pull-up은 3.3V 라인에 연결 |

> **Pull-up 연결 구조**: DATA 핀 ─── 4.7kΩ ─── 브레드보드 3.3V  
> VCC = 3.3V이므로 DATA 신호 최대 전압 = 3.3V → ESP32 GPIO 허용 범위 내 안전.

### ESP32

| 핀 | 연결 |
|---|---|
| 5V (VIN) | 브레드보드 5V |
| 3V3 | 브레드보드 3.3V 라인 공급 |
| GND | 공통 GND |
| GPIO (릴레이) | 릴레이 IN 핀 |
| GPIO (센서) | DHT22 DATA 핀 |

### Buck 컨버터 (LM2596S)

| 핀 | 연결 |
|---|---|
| Vin (+) | 브레드보드 12V |
| Vin (-) | 공통 GND |
| Vout (+) | 브레드보드 5V |
| Vout (-) | 공통 GND |

> 출력 전압 5V로 사전 조정 후 연결할 것.
